# Babacan Portal | Muhasebe, Yazılım & Finans

Web tabanlı muhasebe, yazılım ve finans araçları portalı.

## Özellikler

- 📊 Canlı piyasa şeridi
- 💰 Muhasebe hesaplama araçları
- 📈 Finans takip modülleri
- 🎨 Dark / Light / Corporate tema seçenekleri
- 📱 Mobil uyumlu tasarım

## Kurulum

Bu proje statik bir HTML dosyasından oluşmaktadır. Sadece `index.html` dosyasını bir tarayıcıda açarak kullanabilirsiniz.

```bash
# GitHub Pages ile yayına almak için:
# 1. Bu depoyu GitHub'a yükleyin
# 2. Ayarlar > Sayfalar (Settings > Pages) bölümünden kaynağı seçin
# 3. Siteniz yayında olacaktır
```
